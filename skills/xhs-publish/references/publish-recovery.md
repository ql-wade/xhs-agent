# 上传与提交恢复

## 浏览器工具通用原则

工具响应和页面状态分别记录。先读取当前工具文档，只使用该工具支持的文件选择、审批和页面操作接口；不把某一浏览器 API 名称当作所有环境的通用方法。

| 观察 | 下一步 | 停止条件 |
|---|---|---|
| 选文件调用未返回，没有审批证据 | 检查调用是否仍运行，并读取页面进度；记录“原因未知” | 调用仍运行时不叠加选择文件 |
| 文件选择器未出现、超时且未选文件；原调用已结束，页面无媒体或进度 | 改用页面当前可见上传入口调用工具支持的文件选择方式一次 | 未确认空状态或调用终止时不重试 |
| 明确显示上传审批等待 | 按工具审批流程等待用户决定；审批超时后重新读页面 | 不绕过审批；不据此推断此前调用的原因 |
| 调用超时，但页面已有媒体和处理进度 | 继续观察原编辑页，待处理完成 | 不重新上传 |
| 无媒体、无进度，原调用已终止且页面明确失败 | 核对文件可访问性、格式及错误；修复后有限重试一次 | 再失败或仍未知就保留现场、报告阻碍 |
| 上传已完成、表单出现 | 核对媒体预览、封面、时长及内容版本 | 不以按钮可点击作为唯一上传证据 |
| 点击发布超时/页面无明确结果 | 只读检查成功页、内容管理和草稿中的匹配内容 | 未知结果不再次点击、不重跑全流程 |

每次重试前记录上次操作、页面证据和为何确认可重试。避免刷新或导航导致未保存素材丢失；需要退出时，在相应手动保存授权范围内保存草稿并核验草稿存在，不能仅凭保存命令返回声称成功。

未手动保存也可能因平台自动保存产生本地草稿。操作前后在同一浏览器环境核对笔记、草稿数量与匹配条目，记录存储范围；自动保存不等于发布。告知测试残留，未授权不删除草稿或清除浏览器存储。

## 小红书专用核验

- 上传后核验的是创作者平台实际编辑页，不是文件选择窗口。视频转码未完成时继续观察；页面错误、表单校验及正文限制逐项检查，不把发布无响应一律归因于字数。
- 上传恢复和提交恢复都要查内容管理、草稿中的匹配条目；发现重复条目时报告，不擅自删除。
- 成功提示支持“平台确认提交”；内容管理显示“审核中”支持“待审”；显示“已发布”后仍需进入匹配详情。视频能启动且时间推进才支持“可播放”。每条结论记录观察时间与入口。
- 通过成功页的分享入口复制原链接，打开验证内容及访问条件。保留必要的 `xsec_token` 等平台参数；链接仅在登录创作者入口可播放时注明此范围。裸链接失败就不得交付为可分享链接。

## 本地交付记录模板

```text
任务/素材版本：
执行环境、账号非敏感标识：
授权依据、范围、是否已消耗：
上传调用结果 / 页面实际状态 / 时间：
预览：媒体、封面、标题、正文、话题、可见范围：
去重：检查入口、匹配条目与判断依据：
测试前后笔记/草稿基线、条目变化、存储范围：
是否手动保存 / 是否实际自动保存 / 残留告知与清理授权：
提交：未尝试 / 已尝试结果未知 / 平台确认，时间与证据：
审核：未知 / 审核中 / 已发布 / 拒绝，时间与证据：
详情访问 / 视频播放：未验证或验证入口、登录条件、时间：
分享：原链接已验证的访问范围 / 未取得 / 不可用：
剩余阻碍及下一步只读核验：
```

截图和记录先去除登录凭据、个人信息及会话参数；含分享参数的链接只在用户授权的交付渠道提供，不提交到公开仓库。
