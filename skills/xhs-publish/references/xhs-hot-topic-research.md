# 小红书热点选题研究方法

> 当用户要求「找小红书热点」「看看什么题材火」「选个爆款方向」时使用。

## 核心挑战

| 障碍 | 原因 | 解决方案 |
|------|------|---------|
| **主站 IP 拦截** (300012) | Browser 工具的 Chrome 实例被标记为机器人 | 用用户本地 Chrome 9222 的已登录会话 |
| **搜索引擎验证码** | Google/Bing/百度/知乎全部触发人机验证 | 不依赖搜索引擎，用替代数据源 |
| **Bridge 扩展未连接** | openclaw Chrome 禁用扩展 | 用纯 CDP 操作 |
| **CLI Bridge 不可用** | 同上 | 切换到 XiaohongshuSkills 纯 CDP 模式 |

### 2️⃣ 行业知识库综合法（搜索引擎全挂时）

当所有外部数据源都不可用时，基于以下维度人工合成热点清单：

#### 🔥 五大选题方向（永远有效）

| 方向 | 爆点逻辑 | 案例 |
|------|---------|------|
| **平台级大事件** | 全网讨论，最大流量池 | Sora公测、可灵升级、Google VEO |
| **赚钱/变现类** | 小红书用户最爱 | 月入X万、接广告、代运营 |
| **数据冲击类** | 强对比=强传播 | 成本5000→0、3天→3分钟 |
| **人设故事类** | 最容易共情 | 00后涨粉20万、宝妈副业、剪辑师转型 |
| **当下细分热点** | 从创作者后台实时获取 | 科技数码榜头部博主方向 |

#### 📊 人设故事公式（最高转化率模板）

```
[反差人设] + [零基础] + [用AI工具] + [震撼结果] + [时间短]

示例：
「00后 / 大学生 / 零剪辑基础 / 用Codex自动生成视频 / 1个月涨粉20万」
「宝妈 / 带娃同时 / AI自动出图+文案 / 月入超过主业 / 每天30分钟」
「5年剪辑师 / 从抗拒到真香 / 全流程AI化 / 效率翻10倍 / 第3天就上手」
```

## Pitfalls

1. **不要在主站 www.xiaohongshu.com 上浪费时间** — IP 拦截几乎必然发生
2. **不要反复尝试搜索引擎验证码** — 全部会失败，直接切换到备选方案
3. **Creator 后台数据足够做选题判断** — 有话题热度、博主排行、活动信息
4. **人设故事 > 纯技术介绍** — 小红书用户更关心「谁用了」「效果如何」而非「技术架构如何」
5. **具体数字 > 模糊描述** — 「涨粉20万」比「涨粉很多」有说服力100倍
