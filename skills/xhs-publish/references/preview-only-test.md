# 云端体验测试：只上传、填写和预览

当用户明确要求“测试体验，不发布”时使用。记录授权为“仅准备”，不沿用历史单条发布授权。整个测试不点击发布、确认发布或定时提交，不调用 `publish`、`publish-video`、`click-publish`；已有成功案例不能替本次测试提供提交权限。

准备测试可能自动创建或更新草稿，即使未点击保存或“暂存离开”。这是可预期的编辑副作用，不能据此推断已发布，也不能声称没有残留。当前浏览器本地草稿可能不跨浏览器同步；不擅自删除草稿或清除本地存储。

## 执行

1. 在助手云端电脑先读取当前浏览器工具文档及页面状态，确认登录账号是用户指定目标、上传文件在云端可访问。素材使用用户已有版本，不复制私人素材、账号信息或令牌到仓库。
2. 上传前确认视频/图片可解码、视频可播放、封面、文案与归因一致，记录素材版本和页面初始状态。若素材缺失或登录不可用，交付具体阻碍；不切换到 Mac 浏览器。
3. 进入编辑器前只读记录内容管理的笔记数量、原笔记状态，以及草稿数量、可识别条目和平台显示的存储范围，作为同一浏览器环境的基线；区分本地草稿与平台笔记。只读查看内容管理和草稿是否已有匹配内容。若存在，优先查看现有草稿预览，避免为了测试新增重复上传。无法确定匹配关系时先核验。
4. 用云端工具支持的正常文件上传接口选择一次既有素材。遇到挂起或审批超时，按 publish-recovery.md 读取实际页面和调用状态，不能重复堆叠上传，也不能绕过审批。若文件选择器未出现、调用已超时且未选文件，先读页面确认无媒体/进度、原调用已终止，再使用当前可见上传按钮打开工具支持的文件选择器，选择文件一次；没有这些证据不重试。
5. 在实际编辑页填写已确定的标题、正文和话题，设置并核验封面。正文输入后读回全文；辅助功能键入可能将光标放回开头，不依赖原光标位置。改用工具支持的编辑器填入方式，再明确定位末尾并选择真实平台话题，读回正文顺序与话题。观察视频处理状态、实际媒体预览、话题选择、字数提示、可见范围及定时设置。不要为了观察而触发提交按钮。
6. 停在可审查预览，报告上传和填写是否完成。通过安全的只读入口核对测试后的笔记与草稿基线、匹配条目和存储范围，必要时读取草稿抽屉；不要为了检查而导航丢失现场。基线不可读取时报告未知。新增或更新草稿时明确告知残留，即使没有手动保存。保留当前页；需要退出时，仅在用户授权手动保存草稿的范围内保存并核验。没有相应授权不擅自手动保存、丢弃、删除或清除本地存储，平台自动保存另行记录。

## 输出证据（脱敏）

- 工具环境、素材版本与执行时间；授权“仅准备”。
- 预检、去重、上传、视频处理、封面、文案、话题和预览的各自观察结果；标明使用云端浏览器适配流程还是 CLI/Extension Bridge，不能跨执行路径宣称通过。
- 测试前后笔记与草稿数量、匹配条目、原笔记状态、草稿存储范围；自动保存/残留已告知，是否手动保存与是否实际产生草稿分别记录。删除残留须另有相应授权，本测试不包含删除。
- 异常调用与页面状态分别记录，原因未知时明确未知。
- 截图或摘要不含私人账号信息、Cookie、令牌、私人素材和本地机器路径；公开 PR 仅放脱敏结论。
- 明确写“未尝试提交；审核、公开详情、视频公开播放和分享链接未测试”。编辑器预览能播不能报告为公开视频能播。
- 测试通过仅说明已测的准备与预览环节可用；本次保持草稿 PR，不合并。后续体验验证和审查通过后再评估合并。
