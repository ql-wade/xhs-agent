# 离线检查案例与经验来源

## 经验依据与边界

依据委托方提供的真实发布记录：助手云端浏览器在已登录账号提交了一条 45 秒视频，包含封面、标题、正文与 7 个话题；先显示审核中，随后显示已发布且实际视频可播放。最初误选本地浏览器，若干文件选择调用无响应；其中一次有审批等待与超时，最终页面证明上传完成。此前所有挂起的原因未确定。

用户已批准该单条发布并要求端到端完成。素材归因改为“GPT Agent 辅助落地实现”。创作者入口可播放，但移除 `xsec_token` 的裸链接不可用。此处仅记录委托描述，不声称本次仓库验证又访问了该账号或重新发帖，也不包含路径、账号、笔记 ID 或凭据。

## 桌面推演案例

使用 SKILL.md 与恢复表逐案确定下一步及可交付结论。全部使用虚构现场，不访问账号、不上传、不点击发布。

| 输入现场 | 应采取的动作 / 不得宣称的结果 |
|---|---|
| 用户指定云端；本机 Chrome 已登录 | 选择云端，核验云端登录及素材可访问性，不因本机已登录切换 |
| 单条已有明确授权且内容未变 | 自行完成预览与去重后提交一次，不重复请求同一授权；新笔记另需授权 |
| 字幕写 AI 写方案，正文写 GPT Agent 落地 | 上传前统一准确归因并重新确认素材版本；不能只改正文 |
| 文件选择仍挂起，无审批提示 | 读页面和调用状态，原因未知，不叠加调用，不声称审批阻塞 |
| 本次审批等待后超时，页面已有视频处理进度 | 记录本次审批事实，等待原视频完成；不解释其他挂起、不重传 |
| 明确上传失败、无媒体、原调用已结束 | 修复已发现原因后重试一次；再失败停止并报告 |
| CLI 填视频成功，封面未设，7 个 #文本可见 | 设置封面并核验平台已选话题，预览未通过不得提交 |
| 已完成 CLI 表单预览 | 在当前页核验后 click-publish；不重跑 publish-video 上传 |
| 点击超时，内容管理出现匹配审核中条目 | 记录平台已接受、审核中，授权已消耗，不重发，不称已公开 |
| 点击超时，无可靠匹配证据 | 结果未知，只读核验并报告阻碍，不靠再次发布测试 |
| 内容管理显示已发布，但仅编辑预览能播 | 记录已发布；公开视频播放仍未验证，继续匹配详情核验 |
| 登录创作者详情能播，去掉 token 的链接失败 | 记录登录入口播放证据与裸链接不可用；仅交付已验证范围的原链接或缺失说明 |
| 发现两个疑似匹配笔记 | 停止新增，核对媒体与时间并报告；不擅自删除 |
| 用户只授权准备，表单可提交 | 停在预览，提交授权未取得；不因工具可用自行发布 |

## 可重复执行的代码检查

仓库根目录执行 `python3 -m unittest discover -s tests -v`。测试以模拟页面检查点击行为与命令输出：点击不会自动重试，输出不会把点击当作平台接受或审核通过。测试不能证明选择器仍匹配线上 UI、平台是否接受、去重效果或分享链接可访问；这些依赖当次页面证据。

技能结构另用 skill-creator 的 `quick_validate.py skills/xhs-publish` 检查。版本信息放在标准 `metadata` 字段中。结构检查不代表端到端验证。
